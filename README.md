# Roadmap Task System

A self-hosted, local-first task management and synchronization system designed to maintain Markdown roadmaps as the single source of truth. Features a deterministic review-first pipeline, cryptographic approval workflows, and two-way Google Tasks synchronization.

## Features
- **Guarded Writer**: Exclusively applies approved, hashed operations to roadmap Markdown.
- **Review Pipeline**: Terminal-based diff proposals for any additions, edits, and deletions.
- **Google Tasks Mirror**: Two-way synchronization that links roadmap files to Google Tasks lists, pushing Markdown updates and ingesting completed status checks.
- **Strict Data Locality**: Fully offline, completely repo-local operations pipeline.
