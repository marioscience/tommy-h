## 🎮 PART 1: Gamer & Gameplay Tests (For QA Tester)

*Straightforward instructions to play and stress-test the server like a real customer.*

### Step 1: Deploy Server & Inject GSLT Token 🎮
- **What to do**: Deploy CS2 in panel, input Steam Game Server Login Token (GSLT), and start.
- ✅ **PASSED IF**: Starts up and binds port 27015 TCP/UDP.
- ❌ **FAILED IF**: GSLT invalid error or startup abort.

### Step 2: Connect via Developer Console 🎮
- **What to do**: Open CS2, open console (~), type: connect <IP:27015>.
- ✅ **PASSED IF**: Loads map (de_dust2/de_mirage) and prompts team selection (CT/T).
- ❌ **FAILED IF**: Connection failed after 30 retries error.

### Step 3: Volumetric Smoke & Grenade Sync 🎮
- **What to do**: Throw a smoke grenade while two players watch from different angles.
- ✅ **PASSED IF**: Volumetric smoke plume renders identical geometry and dissipates simultaneously on both clients.
- ❌ **FAILED IF**: Smoke desync allows one player to see through the cloud.

### Step 4: Competitive Matchpad Console 🎮
- **What to do**: In panel, open Matchpad tab, click "Restart Round" or send changelevel.
- ✅ **PASSED IF**: Match immediately resets in-game or loads designated competitive map.
- ❌ **FAILED IF**: Command is ignored or drops connection.

## ⚙️ PART 2: Technical Engine Tests (For Developers)

*Terminal commands and Docker inspection verified by developers in 3 minutes.*

### Tech Check 1: Rootless Ownership Normalization Helper ⚙️
- **Command / Action**: `docker inspect <cs2-container>`
- **Pass Criteria**: normalizeCS2DataOwnership successfully aligned volume UID to 1000:1000 inside Docker namespace.

### Tech Check 2: Sub-Tick Packet Rate & Socket 27015 ⚙️
- **Command / Action**: `docker logs <cs2-container> | grep -i "tick"`
- **Pass Criteria**: Source 2 socket operates without packet buffer overflows during rapid rifle spray sequences.

### Tech Check 3: server.cfg Visual Persistence ⚙️
- **Command / Action**: `cat <dataPath>/game/csgo/cfg/server.cfg`
- **Pass Criteria**: Competitive convars edited via web UI persist cleanly to disk.
