# Privacy Policy

**Roadmap-Task-System** accesses Google Tasks data via the Google Tasks API solely to sync your own roadmap files with your own Google account.

* **What the app does**: Reads and writes the user's own Google Tasks via OAuth 2.0 to maintain a two-way synchronization with local Markdown roadmaps.
* **What data it stores**: OAuth tokens (`token.json`) and task data stay exclusively on the user's own machine and within their own Google account.
* **Third parties**: No data is shared with, sold to, or accessible by any third party.
* **Data retention**: User-controlled. To revoke access and delete data, simply delete the local `token.json` file and revoke the app's access in your Google Account security settings.
* **Contact**: For questions or concerns, please visit the [repository's GitHub issues page](https://github.com/marioscience/tommy-h/issues).
